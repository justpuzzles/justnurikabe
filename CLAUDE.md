# CLAUDE.md — Just Nurikabe

iPhone and iPad puzzle game (iOS 18.0+ since 1.1; simulators still pin OS=18.5) that teaches Nurikabe (the island puzzle).
Clone #5 of the Just Puzzles family (`../kakuro` → `../hashi` → `../numeriqo` →
`../shikaku`): same architecture and invariants, its own look ("the chart":
indigo sea band, SF Expanded display, rounded numerals, ochre for teaching;
positioning against the siblings in `docs/DESIGN.md`). Engineering notes:
`docs/ENGINEERING.md`; the learning path: `docs/TEACHING.md`; the ladder:
`docs/TECHNIQUES.md`; rules: `docs/RULES.md`.

## Critical invariants

- **Never edit project.pbxproj to add files.** Synchronized root groups: every
  file under `Nurikabe/` and `NurikabeTests/` joins its target automatically.
- **`Nurikabe/Engine/` is pure**: Foundation only, every type `nonisolated` +
  `Sendable`. It must compile as a CLI:
  `swiftc -O -o /tmp/nurikabe-enginecheck Nurikabe/Engine/*.swift "$(Tools/puzzlekit-sources.sh)"/*.swift Tools/EngineCheck/*.swift`.
- **PuzzleKit (since 1.2)** is a Swift package from
  github.com/justpuzzles/PuzzleKit, pinned to a revision in the project
  (`Package.resolved`); a plain clone builds. To work on the kit, drag a local
  `../PuzzleKit` into the project (it overrides the remote one) or set
  `PUZZLEKIT=../PuzzleKit` for the engine build; bump the pin when the kit changes. It owns
  `DayKey`/`DaySeed`, the three save slots (`SaveSlots`, under 1.1's
  `savedGame`/`savedDaily`/`savedPractice` keys), the streak record
  (`DailyRecord` under `nurikabe.daily.v1`, built once from 1.1's
  `nurikabe.dailies.v1`, which is still written for a downgrade), `TodayClock`
  and the daily share text. `App/PuzzleKitExports.swift` re-exports it; engine
  files import it behind `#if canImport(PuzzleKit)`. Never change the seed
  prefix (`nurikabe-daily-`), the hash or `isoString`. Record dailies oldest
  first when seeding test data: an older day after a newer one is a late solve.
- **`Theme` and `Motion` are `nonisolated` — load-bearing.** Project default
  isolation is MainActor; a dynamic-colour provider inheriting it traps when
  UIKit resolves off-main. Guarded by `ThemeIsolationTests`.
- Every shipped board is unique (`BacktrackingSolver`) AND solvable by
  `LogicalSolver` under its grade's ceiling — enforced in
  `NurikabeGenerator.generate`, re-proven by EngineCheck. Deterministic node
  budgets, seeded RNG, baked fallbacks.
- `LogicalSolver` applies the **lowest applicable technique**.
  `BacktrackingSolver` is uniqueness only and keeps its own propagation; it
  shares exactly one function with the teaching solver (`reachable`).
- `Technique` declaration order is the single source of truth (solver loop,
  weights, hint ladder, lesson order, practice).
- **Lesson positions are baked** (`Engine/LessonBoards.swift`, generated by
  `NURIKABE_LESSONS=1`). Never hand-edit; regenerate after any change to the
  generator or techniques, then run EngineCheck and the tests.
- A lesson's targets are exactly its step's cells (`LessonSession`). Rule
  positions are cut so that set equals the blanks.
- The engine never holds a string. All English is in
  `Teaching/TechniqueContent.swift` (and the paywall copy in `Store/Entitlement.swift`).
  Never share a sentence with a sibling app (4.3(a)).
- All gating lives in `FeatureGate` (pure, `unlocked:` passed in). Paid rows
  stay tappable and open the paywall; only order-locked path steps are disabled.
- `EntitlementSource.isOwned` returning `nil` never downgrades a cached unlock.
- Navigation destinations of the same type get `.id(route value)`: finishing a
  lesson replaces the top of the path with the next lesson, and without an id
  SwiftUI keeps the old lesson's @State.
- Persistence saves on every change; lesson steps are recorded when solved, not
  when Continue is tapped.

- **Mac, Apple TV and Vision Pro (branch `multiplatform`, 2026-11-12).** One
  target, `SDKROOT = auto`, as in Hashi and Kakuro. Platform differences go
  through `Design/PlatformSeams.swift` (inline titles, list backgrounds,
  `.tile`/`focusLift`, `listRowButton`, `bareButton`, `Metrics`, `VoiceOver`),
  never scattered `#if`s in views.
  - *Mac*: click and drag paint as on iPad; a light ring follows the pointer.
    Keys come from an `NSEvent` monitor (`Game/BoardKeys.swift`, never
    SwiftUI focus): arrows move a cursor, Space/Return cycle, S sea, D or .
    dot, Delete clear. Menu bar: Undo/Redo Mark (⌘Z/⇧⌘Z), Game › Hint (⇧⌘H)
    via `GameCommands` + `focusedSceneValue` (Mac only, `BoardActions`
    compared by flags). Window 1100×820, min 720×620. Sandboxed
    (`Nurikabe-macOS.entitlements`). `Theme` has an `NSColor` dynamic path.
  - *Apple TV*: one focus stop per cell over the Canvas; Select is a tap. The
    ring is paper outside, ink inside, so it shows on sea and land. No toolbar
    anywhere (focus trap): Stats/Settings are Home rows, Clear joins the tools
    (2×2, labels beside icons). List rows use `.tile` (the system's white focus
    plate hid the chart's text). Columns ×1.5, lesson boards 640. No share.
  - *Vision Pro*: gaze targets per cell (before the stroke gesture, so
    pinch-drag still paints); the room is tinted glass (`Theme.ground` 0.55),
    the chart stays opaque; borderless tools; wide window 1180×860.
  - Icons: `Tools/AppIcon/make_platform_icons.py` (sea back layer, islands
    front layer keyed out of the iOS icon; Mac rounded tiles).

## Build & test

```bash
# Engine, no simulator (seconds; NURIKABE_CORPUS=n boards per size×tier):
swiftc -O -o /tmp/nurikabe-enginecheck Nurikabe/Engine/*.swift "$(Tools/puzzlekit-sources.sh)"/*.swift Tools/EngineCheck/*.swift && /tmp/nurikabe-enginecheck
NURIKABE_CALIBRATE=1 /tmp/nurikabe-enginecheck   # score percentiles per technique floor
NURIKABE_BAKE=1 /tmp/nurikabe-enginecheck        # fresh BakedPuzzles literals
NURIKABE_LESSONS=1 /tmp/nurikabe-enginecheck > Nurikabe/Engine/LessonBoards.swift

# App + tests (pin OS=18.5):
xcodebuild -project Nurikabe.xcodeproj -scheme Nurikabe -destination 'platform=iOS Simulator,name=iPhone 16 Pro,OS=18.5' build
xcodebuild test -project Nurikabe.xcodeproj -scheme Nurikabe -destination 'platform=iOS Simulator,name=iPhone 16 Pro,OS=18.5' -parallel-testing-enabled NO

# Icon (CoreGraphics, opaque PNG):
swiftc -o /tmp/nurikabe-icon Tools/AppIcon/make_icon.swift && /tmp/nurikabe-icon
```

Debug launch flags: `-uiTestResetState` (wipe defaults), `-NurikabeScreenshotUnlock`
(paid screens), `-NurikabeScreenshotScene <hint|lesson|path|home|win>` (seeded
store scenes). All live inside `#if DEBUG`, strings included (StoreTests checks).

App Store kit: `AppStore/SUBMISSION.md` (runbook and what's left),
`AppStore/capture_screenshots.py`, `AppStore/iap/generate.py`, site pages in
`AppStore/`, and `Tools/ListingCheck/sentence_diff.py` (4.3 sentence guard, exit 1
on any sentence shared with a sibling).

## Layout

- `Nurikabe/Engine/` — Models (Grid, Puzzle, Groups, Rules), Technique, LogicalSolver,
  BacktrackingSolver, NurikabeGenerator (layout → uniqueness repair → 1-folding),
  Difficulty, DailySeed, LessonPositions + LessonBoards, BakedPuzzles, RNG
- `Nurikabe/Game/` — NurikabeGame (@Observable service), BoardView (Canvas), GameView, PuzzleCache
- `Nurikabe/Teaching/` — HintEngine, TechniqueContent, LessonSession, LessonBoardView,
  RuleLessonView, TechniqueLessonView, LearnPathView
- `Nurikabe/App/` — NurikabeApp, ContentView, Route, HomeView (+ NewBoardSheet), PlayHostView, Stats, Settings
- `Nurikabe/Store/` — FeatureGate/PaidFeature, EntitlementStore (StoreKit 2), PaywallPresenter, PaywallView
- `Nurikabe/Persistence/` — ProgressStore (`nurikabe.*.v1` keys, `init(userDefaults:)`)
- `Tools/EngineCheck/`, `Tools/AppIcon/`, `StoreKit/Nurikabe.storekit`, `docs/` — outside
  `Nurikabe/` so they never ship in the bundle
